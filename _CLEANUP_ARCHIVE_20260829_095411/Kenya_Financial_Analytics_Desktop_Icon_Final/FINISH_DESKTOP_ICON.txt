KENYA FINANCIAL ANALYTICS - FINAL DESKTOP ICON

1. Put these three files together in one folder:
   - kenya_financial_analytics.ico
   - Apply_Kenya_Financial_Icon.ps1
   - Apply_Kenya_Financial_Icon.bat

2. Double-click:
   Apply_Kenya_Financial_Icon.bat

3. The script will:
   - copy the icon into your project's icons folder
   - update the "Kenya Financial Analytics" desktop shortcut
   - keep your existing VBS launcher
   - refresh Windows Explorer

Your existing working application is not rebuilt or changed.

Expected project path:
C:\Users\ADMIN\Desktop\Quantative Finance Project\Kenya_Financial_Analytics
